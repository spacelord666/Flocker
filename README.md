# Flocker
Spam a license plate detection camera with useless information

This is part of the FLock OFF project.

Written by DTMF.


How to use:

Install pygame:

Bashpip install pygame

Save the script as license_plate_display.py
Run it:

Bashpython license_plate_display.py
Features:

Full screen display
Realistic license plate formatting (ABC 1234)
Large, bold font suitable for plates
White text with subtle border on black background
Customizable number of plates and display duration
Press ESC to exit early
